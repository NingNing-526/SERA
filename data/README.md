# 大模型生成数据

本仓库不包含以下数据文件。表格与 manifest.json 仅保留历史实验缓存的参考信息，不能视为文件已随仓库提供。请自行准备兼容数据，内容不要裁剪或重排。

| 文件 | 用途 | 参考文件大小 |
|---|---|---:|
| mosi/mosi_gemma_raw_v11.json | MOSI 三模态自然语言描述、原始生成记录、回退标志、样本 ID 和提示词元数据 | 4,875,761 字节 |
| mosi/gemma_semantic_tokens_v11_len256.pt | MOSI 下游训练使用的词元级语义特征及掩码 | 8,648,572,306 字节 |
| mosei/gemma_semantic_tokens_v11_len256.pt | MOSEI 下游训练使用的词元级语义特征及掩码 | 89,891,551,958 字节 |

`.part` 后缀表示下载或校验尚未完成，不能直接用于训练。完整文件应通过来源文件的 SHA-256 对比后才移除此后缀。请自行校验实际取得的文件。

MOSI 描述包含 train=1284、valid=229、test=686，每个划分均有 text/audio/vision 描述和同样数量的 ID；原文件已与服务器 SHA-256 对照一致。

MOSEI 的语义缓存包含 train/valid/test 的 IDs、text/audio/vision 特征及有效掩码，不包含可还原的原始描述文本。目前尚未找到该缓存对应的原始描述 JSON，不将推测或重新生成的内容冒充原记录。即使缺少这个 JSON，下游训练仍可直接读取完整 `.pt` 缓存。

仍需自行准备对应的 `unaligned_50.pkl` 和本地 BERT-base-uncased。项目默认语义缓存路径已与以上目录一致；也可以通过命令行传入自己的本地路径。

训练用 `.pt` 和原始 `.pkl` 仅应加载可信文件。缓存合计约98.54 GB，完整归档使用 ZIP64，大文件解压需足够磁盘空间及支持 ZIP64 的工具。生成数据与预训练模型的公开分发权限需要在分享前另行确认。
